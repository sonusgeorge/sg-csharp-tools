# SG Tools 2.0 (C#)

Revit add-ins written in C# against the Revit API, built as a learning project.

- **Ribbon tab:** SG Tools 2.0
- **Built for:** Revit 2027
- **Status:** not started, the pyRevit versions come first

Each tool here is a C# rebuild of a tool from [sg-pyrevit-tools](https://github.com/sonusgeorge/sg-pyrevit-tools).
